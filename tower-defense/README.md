# 픽셀 타워 디펜스

동굴에서 나온 몬스터가 길을 따라 성으로 걸어옵니다. 길옆 풀밭에 탑을 지어서 성에 닿기 전에 막아내는 2D 픽셀 타워 디펜스 게임입니다.
빌드 과정 없이 `index.html` 하나만 브라우저로 열면 바로 실행됩니다. 인터넷이 없어도 됩니다.

## 하는 법

1. 첫 화면에서 맵을 고릅니다.
2. 아래 칸에서 탑을 고르고(또는 숫자 1~4) 풀밭을 눌러 짓습니다. 고르면 지을 수 있는 칸에 모서리 표시가 나오고, 마우스를 올리면 사거리가 보입니다.
3. **▶ 웨이브 시작**을 누르면 몬스터가 나옵니다. 몬스터를 잡으면 골드가 들어옵니다.
4. 몬스터가 성 문에 들어가면 생명이 줄어듭니다. 생명이 0이 되면 패배, 20웨이브를 버티면 승리입니다.

| 동작 | 키보드·마우스 | 휴대폰 |
| --- | --- | --- |
| 탑 고르기 | 1~4, 아래 칸 클릭 | 아래 칸 탭 |
| 탑 짓기 | 풀밭 클릭 (Shift를 누르고 있으면 계속 짓기) | 같은 칸을 두 번 탭 (첫 탭은 미리보기) |
| 탑 정보 | 탑 클릭 | 탑 탭 |
| 업그레이드 / 판매 / 공격 대상 | U / S / T | 아래 버튼 |
| 다음 웨이브 | Space | 오른쪽 아래 버튼 |
| 취소 | Esc, 오른쪽 클릭 | × 버튼 |
| 속도 ×1·×2·×3 / 일시정지 / 소리 | F / P / M | 위쪽 버튼 |

다른 탭으로 넘어가면 자동으로 일시정지됩니다.

## 탑

탑마다 3단계까지 업그레이드할 수 있고, 단계가 오르면 탑 띠 색이 갈색 → 파랑 → 금색으로 바뀝니다. 팔면 들인 골드의 70%를 돌려받습니다.

| 탑 | 값 | 특징 | 1단계 → 3단계 |
| --- | --- | --- | --- |
| 궁수탑 | 50 | 빠른 화살로 한 마리씩. 공중 공격 가능, 물리 | 공격력 8 → 24, 초당 1.6 → 2.3발, 사거리 2.7 → 3.4칸 |
| 대포탑 | 80 | 포탄이 터지며 주변까지 피해. **공중 공격 불가**, 물리 | 공격력 20 → 58, 폭발 반경 20 → 27 |
| 얼음탑 | 70 | 맞은 곳 주변 적을 느리게 함. 마법 | 둔화 35% → 55%, 1.6초 → 2.4초 |
| 번개탑 | 110 | 번개가 가까운 적에게 튐 (튈 때마다 80%). 마법 | 공격력 17 → 44, 3마리 → 5마리 |

업그레이드 값은 궁수탑 60/110, 대포탑 90/150, 얼음탑 75/120, 번개탑 115/180입니다.
**마법** 공격은 갑옷을 무시하고, **물리** 공격은 갑옷만큼 피해가 줄어듭니다.
공격 대상은 선두(성에 가장 가까운 적), 후미, 강한 적(체력이 가장 많은 적), 가까운 적 중에서 고릅니다.

## 몬스터

| 몬스터 | 특징 | 성에 들어가면 |
| --- | --- | --- |
| 슬라임 | 기본 | 생명 -1 |
| 고블린 | 빠름 | -1 |
| 박쥐 | 하늘을 날아서 대포탑이 못 맞힘 | -1 |
| 오크 전사 | 갑옷 40% | -2 |
| 바위 골렘 | 느리지만 갑옷 55% | -5 |
| 슬라임 킹 (10웨이브 보스) | 쓰러지면 슬라임 8마리로 나뉨 | -6 |
| 화염 드래곤 (20웨이브 보스) | 날아다니는 최종 보스 | -12 |

몬스터 체력은 웨이브가 오를수록 늘어납니다. 위쪽 표시줄의 **다음** 칸에서 다음 웨이브에 나올 몬스터와 수를 미리 볼 수 있고, 보스가 나오면 화면 위에 보스 체력바가 뜹니다.
얼음탑의 둔화는 보스에게 절반만 통합니다.

## 웨이브와 골드

- 웨이브를 모두 잡으면 클리어 보너스(8 + 웨이브 번호)를 받고, 15초 뒤 다음 웨이브가 저절로 시작됩니다.
- 그 전에 **다음 웨이브**를 누르면 남은 초만큼 보너스 골드를 받습니다 (5웨이브마다 초당 보너스가 1씩 올라감). 몬스터가 아직 남아 있을 때도 부를 수 있습니다.
- 승리하면 남은 생명으로 별을 받습니다: 18 이상 ★★★, 10 이상 ★★, 그 밖에 ★. 이어서 **무한 모드**로 계속하면 웨이브가 끝없이 강해지고 10웨이브마다 보스가 나옵니다.
- 맵별 최고 별과 무한 모드 최고 웨이브는 브라우저에 저장됩니다.

## 만든 방식

- 화면은 320×192 픽셀(16픽셀 타일 20×12칸) 캔버스에 그리고, 창 크기에 맞춰 가능하면 정수 배로 키웁니다. 위 표시줄과 아래 탑 칸은 HTML이라 글자가 선명합니다.
- 몬스터, 탑, 나무, 아이콘은 모두 코드 안의 문자열 도트 그림(`R` 객체)으로 그립니다. 글자 하나가 픽셀 하나이고, `PAL`이 글자별 색입니다. 맞았을 때 하얗게 번쩍이는 그림과 느려졌을 때 파란 그림은 시작할 때 미리 만들어 둡니다.
- 바닥, 길, 동굴, 성, 날씨(꽃잎, 모래바람, 눈)는 맵마다 정해진 시드로 그려서 매번 같은 모습입니다.
- 효과음은 Web Audio로 그 자리에서 합성합니다.
- 균형 숫자는 파일 위쪽(`hpScale`, `BETWEEN`, `SELL`)과 `ENEMY`, `TOWER`, `WAVES`, `MAPS`에 모여 있습니다.

새 한국어 문구를 넣으면 글꼴을 다시 골라 넣어야 합니다. 안 하면 그 글자만 시스템 글꼴로 보입니다.

```sh
pip install fonttools brotli
python3 tools/embed_font.py path/to/Galmuri11.ttf   # npm 패키지 galmuri의 dist/Galmuri11.ttf
```
