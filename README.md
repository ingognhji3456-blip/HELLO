# PIXEL BOSS RUSH — GLOOMEYE & STRIKER

보스의 공격 패턴을 피하면서 쓰러뜨리는 픽셀 보스전 게임입니다.
빌드 과정 없이 `index.html` 하나만 브라우저로 열면 바로 실행됩니다.

## 조작법

| 동작 | 키보드 | 모바일 |
| --- | --- | --- |
| 보스 선택 (타이틀) | ← / → | 화면 왼쪽·오른쪽 탭 |
| 이동 | 방향키 / WASD | 화면 드래그 |
| 정밀 이동 (느리게, 판정점 표시) | Shift | - |
| 대시 (짧은 무적) | Space / X | 두 번 탭 |
| 공격 | 자동 발사 | 자동 발사 |
| 일시정지 / 소리 / 전체화면 | P (Esc) / M / F | 상단 전체화면 버튼 |

## 보스

두 보스 모두 체력 66%, 33%에서 페이즈가 바뀌며 패턴이 강해집니다. 첫 번째 보스를 이기면 바로 다음 보스로 이어집니다.

### 1. GLOOMEYE (탄막형 외눈 괴물)
- 원형 탄막, 조준 부채꼴 탄, 회전 나선탄, 탄 비
- Phase 2부터 조준 레이저, 돌진과 충격파, 감속 후 재조준 탄
- Phase 3에서 회전 레이저와 두 패턴을 동시에 쓰는 복합 패턴

### 2. STRIKER (전투기형 로봇, 직접 공격)
- **몸통 돌진**: 빨간 띠로 경로를 예고한 뒤 플레이어를 향해 들이받음
- **기총소사 비행**: 화면을 가로질러 날아가며 아래로 사격 (지나가는 높이를 띠로 예고)
- **기관포**: 가슴 포구에서 플레이어를 천천히 따라오는 연사
- **유도 미사일**: 날개에서 발사되어 잠시 플레이어를 추적
- **급강하** (Phase 2+): 화면 밖으로 날아올랐다가 그림자 위치로 내리꽂힘

플레이어 체력은 하트 5개이며, 피격 판정은 기체 한가운데 한 점뿐입니다. 보스별 최고 기록(클리어 시간)은 브라우저에 저장됩니다.

## 구조

- `index.html`: 게임 전체 (Canvas 240×320, 순수 JavaScript, 외부 라이브러리 없음)
  - 보스는 `BOSSES` 배열에 정의됩니다 (이름, 체력, 판정 크기, 그리기 함수, 페이즈별 패턴).
  - 패턴은 제너레이터 함수(`function*`)이고 `yield 초`로 타이밍을 제어합니다. 새 패턴은 함수를 만들어 해당 보스의 `pools`에 추가하면 됩니다.
  - 효과음은 Web Audio로 실시간 합성합니다.
