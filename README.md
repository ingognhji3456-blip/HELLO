# BLADE RUSH — 픽셀 액션

검을 든 주인공이 달리고, 뛰고, 벽을 타고, 베며 8개 스테이지를 돌파하고 레벨을 올려 스킬을 익히는 횡스크롤 액션 게임입니다.
`action.html`을 브라우저로 열면 바로 실행됩니다 (Canvas 320×180, 순수 JavaScript, 외부 라이브러리 없음). 화면은 16:9 비율로 창을 가득 채웁니다.

## 조작법

| 동작 | 기본 키 1 | 기본 키 2 | 모바일 |
| --- | --- | --- | --- |
| 이동 | ←/→ | A/D | 왼쪽 아래 < > 버튼 |
| 위 / 아래 | ↑/↓ | W/S | V 버튼 (아래) |
| 점프 (공중에서 한 번 더: 공중제비 2단 점프) | Space | Z | JUMP |
| 공격 (연타 3단 콤보, 3타는 전진 강타) | X | 마우스 왼쪽 | ATK |
| 대시 (짧은 무적, 공중에서는 착지 전 1회) | 왼쪽 Shift | C | DASH |
| 패리 | V | 마우스 오른쪽 | PARRY |
| 회전베기 (차지) | 공격 키를 누른 채 0.5초 뒤 놓기 | | ATK 길게 |
| 급강하 베기 | 공중에서 아래 + 공격 | | V + ATK |
| 벽 타기 / 벽 점프 | 공중에서 벽 쪽으로 누르기 → 점프 | | 같음 |
| 발판 아래로 내려가기 | 아래 + 점프 | | V + JUMP |
| 일시정지 / 소리 / 전체화면 | Esc 또는 P / M / F | | 위쪽 일시정지 표시 탭 |

점프 키를 짧게 누르면 낮게, 길게 누르면 높게 뜁니다. 블록 모서리에 몇 픽셀 모자라게 닿으면 자동으로 올라서고, 천장 모서리에 머리가 살짝 걸리면 옆으로 비켜 지나갑니다.

### 키 설정

타이틀의 **CONTROLS** 또는 일시정지 메뉴의 **CONTROLS**에서 모든 동작(이동 4방향, 점프, 공격, 대시, 패리)의 키를 동작마다 2개씩 바꿀 수 있습니다.

- 칸을 고르고 Enter를 누르거나 칸을 클릭한 뒤, 원하는 키를 누르거나 마우스 버튼(왼쪽, 가운데, 오른쪽, 옆 버튼 4·5)을 누르거나 휠을 굴리면 지정됩니다.
- Esc는 취소, Delete나 Backspace는 그 칸을 비웁니다. 이미 다른 동작에 쓰던 키를 지정하면 그쪽에서 빠지고 화면 아래에 알려 줍니다.
- **RESET DEFAULTS**로 기본값으로 돌아갑니다. 설정은 브라우저에 저장됩니다.
- 메뉴는 항상 방향키, Enter, Esc, 마우스 클릭으로도 조작됩니다. M, F, P를 게임 동작에 지정하면 그 키의 소리·전체화면·일시정지 기능은 꺼집니다.

## 클리어 조건

- **스테이지의 모든 적을 처치해야** 끝의 깃발이 열립니다. 깃발이 잠겨 있을 때는 회색에 해골 표시가 붙고, 닿으면 남은 적 수를 알려 줍니다.
- 화면 왼쪽 위 해골 옆 숫자가 남은 적 수입니다. 4마리 이하로 남으면 화면 밖에 있는 적 방향으로 빨간 화살표가 나옵니다.
- **보스 스테이지 (3, 8)** 는 보스 방 앞을 쇠창살 문이 막고 있습니다. 적을 전부 쓰러뜨리면 문이 열리고, 들어가면 보스 **IRON DUKE**와 싸웁니다. 보스를 쓰러뜨리면 깃발이 나타납니다.

## 게임 흐름

- **타이틀**: ←/→로 열린 스테이지를 고르고 START로 시작합니다. HERO에서 레벨과 배운 스킬을 보고, CONTROLS에서 키를 바꿉니다.
- 스테이지를 깨면 다음 스테이지가 열립니다. 스테이지 구간은 미리 만든 블록을 스테이지별 고정 시드로 이어 붙여 만듭니다.
- 하트가 전부 깎이면 그 스테이지를 처음부터 다시 합니다. 구덩이에 빠지면 하트 1개를 잃고 마지막으로 서 있던 땅에서 다시 시작합니다.
- 뒤 스테이지일수록 블록 수가 늘고, 적 체력이 스테이지마다 22%씩 늘어납니다. 대신 적이 주는 XP도 25%씩 늘어납니다.

## 레벨과 스킬

- 적을 처치하면 XP를 얻습니다 (슬라임 8, 박쥐 10, 포탑 12, 궁수 14, 기사·방패병 22, 뒤 스테이지일수록 더 많이). 패리 성공은 3, 퍼펙트 패리는 6, 스테이지 클리어는 40 + 스테이지마다 25, IRON DUKE는 250, DARK DUKE는 600입니다.
- 왼쪽 위 **LV**와 보라색 막대가 레벨과 다음 레벨까지의 진행도입니다.
- **필요 XP**는 레벨마다 약 35%씩 늘어납니다 (최대 레벨 30):

- **레벨 업**하면 금빛 기둥이 솟고 하트 1개가 회복되며, 잠시 뒤 게임이 멈추고 스킬 카드 3장 중 하나를 고릅니다 (←/→와 Enter, 또는 클릭이나 탭). 여러 레벨이 한꺼번에 오르면 연달아 고릅니다. 스테이지 클리어 화면에서 오른 레벨은 다음 스테이지로 가기 전에 고릅니다.

## 전투

- **콤보**: 적을 연속으로 맞히면 HITS 카운터가 오르고, 처치 점수에 콤보 배수(최대 10배)가 붙습니다. 2초 동안 안 맞히거나 피격되면 끊깁니다.
- **3단 콤보**: 1·2타는 가볍고 빠르며, 3타는 앞으로 내디디며 피해 2에 적을 크게 날립니다.
- **회전베기**: 공격 키를 계속 누르면 기를 모으고, 놓으면 앞뒤를 동시에 베는 피해 3의 회전베기가 나갑니다.
- **급강하 베기**: 적을 맞히면 튕겨 올라 다시 점프와 대시를 쓸 수 있습니다.
- **몬스터 몸에 닿기만 해서는 다치지 않습니다.** 공격 동작 중일 때만 피해를 받습니다.
- 맞으면 1.7초 무적이고, 대시 중에도 무적입니다.

### 패리

패리 키를 누르면 검을 몸 앞에 비스듬히 세우고 0.24초 동안 막는 자세를 잡습니다. 앞쪽에서 오는 공격이 이 사이에 닿으면 패리에 성공합니다.

| 패리 대상 | 결과 |
| --- | --- |
| 기사의 베기·돌진, 방패병의 돌격 | 무기나 방패가 위로 튕겨 나가며 뒤로 밀려 1.2초 비틀거립니다. 이때 받는 피해 2배, 방패도 막지 못합니다 |
| 슬라임의 점프, 박쥐의 급강하 | 튕겨 나가며 피해 1(퍼펙트는 2)을 입습니다 |
| 화살, 포탑 탄, 보스 화염탄 | 금색으로 바뀌어 가장 가까운 적에게 날아갑니다. 적에게 피해 2, 보스에게 3 |
| 보스의 베기, 돌진, 내려찍기 착지 | 보스가 뒤로 밀리며 검이 튕겨 올라가는 **STAGGER** 상태가 됩니다. 이때 받는 피해 2배 |
| 보스의 충격파 | 부서집니다 (SHATTER) |

- **퍼펙트 패리**: 자세를 잡은 직후 0.09초 안에 막으면 PERFECT입니다. 패리 자세의 빛이 금색일 때입니다. 화면이 잠깐 느려지고, 금색 섬광과 십자 빛줄기가 터지며, 적이 더 오래 비틀거리고 튕겨낸 탄이 더 빠릅니다.
- **반격 (COUNTER)**: 패리에 성공하면 주인공 머리 위에 "!"가 깜빡이는 동안(0.7초, 퍼펙트는 1초) 공격 키를 눌러 앞으로 돌진하며 찌르는 반격을 씁니다. 피해 4이고, 비틀거리는 적에게는 8입니다.
- **동작**: 자세를 잡으면 검을 세우고 발을 고정하며 몸 앞에 빛나는 막이 생깁니다. 성공하면 검을 위로 쳐올리며 몸이 뒤로 젖혀지고 살짝 밀려납니다. 헛치면 0.28초 동안 검이 처지며 빈틈이 생깁니다.
- 공격 도중에도 패리로 끊을 수 있습니다 (급강하, 회전베기, 반격 중 제외).

### 타격감

- 맞힌 지점에 재질별 충격 별빛과 파편이 튑니다: 갑옷은 금색 불꽃과 금속음, 슬라임은 끈적한 초록 덩어리, 박쥐는 보라색.
- 맞히면 화면이 잠깐 멈추고(강타 0.11초, 처치 0.13초), 적이 그 자리에서 떨리며 흰색에서 붉은색으로 번쩍입니다.
- 카메라가 때린 방향으로 살짝 밀렸다 돌아옵니다. 피해 숫자가 크게 튀어나왔다가 떨어집니다.
- 지상 콤보는 칠 때마다 주인공이 반동으로 조금 밀립니다. 처치하면 큰 파편과 짧은 섬광, 낮은 쿵 소리가 납니다.

## 보스 IRON DUKE (체력 48)

보스는 몸에 닿는 것만으로는 다치지 않습니다. 돌진 중이거나 내려찍으며 떨어질 때만 피해를 줍니다. 동작마다 자세가 따로 있습니다.

| 패턴 | 준비 동작 | 공격 동작 |
| --- | --- | --- |
| 베기 | 뒤로 몸을 젖히고 무릎을 굽히며 대검을 머리 뒤로 끌어올립니다. 눈이 하얗게 빛나고, 막판에 몸이 떨리며 칼끝에 별빛이 맺힙니다 | 앞발을 내디디며 내려칩니다. 붉은 초승달 궤적이 남고, 2페이즈에서는 두 번 연속입니다 |
| 돌진 | 낮게 웅크리고 대검을 창처럼 허리에 수평으로 겨눕니다. 뒷발로 땅을 긁고 망토가 펄럭이며, 붉은 띠 위로 화살표가 달려갑니다 | 몸을 크게 숙이고 달립니다. 망토가 뒤로 수평으로 날리고 붉은 잔상이 따라옵니다. 벽에 부딪히면 무릎을 꿇고 검을 떨어뜨린 채 기절합니다 |
| 내려찍기 | 깊이 웅크리며 두 손으로 대검을 머리 위로 듭니다 | 뛰어오를 때 다리를 접고, 떨어질 때 칼끝을 아래로 꽂으며 망토가 위로 솟습니다. 착지하면 땅이 갈라지고 양쪽으로 충격파가 갑니다. 검을 땅에 박은 채 잠시 웅크립니다 |
| 화염 투척 (2페이즈) | 왼손을 들어 올려 화염구를 모읍니다 | 팔을 앞으로 뻗어 포물선 화염탄 3발을 던집니다 |

- 돌진이 벽에 안 부딪히고 끝나면 미끄러지며 뒤로 젖혀 멈춥니다.

- 체력 50%에서 2페이즈로 바뀌며 갑옷이 붉게 변하고 모든 패턴이 빨라집니다.
- 벽에 박혀 기절했을 때와 STAGGER 상태일 때 받는 피해가 2배입니다.

## 그래픽과 연출

# STRIKER — 픽셀 보스전

전투기형 로봇 보스 **STRIKER**의 공격을 피하면서 격추하는 픽셀 보스전 게임입니다.
빌드 과정 없이 `index.html` 하나만 브라우저로 열면 바로 실행됩니다. 페이지는 게임 전용이라, 게임 화면이 브라우저 창 높이(모바일은 폭)에 맞춰 항상 가득 차고 남는 양옆은 우주 배경으로 채워집니다. F 키를 누르면 모니터 전체화면으로 전환됩니다.

## 조작법

| 동작 | 키보드 | 모바일 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 화면 드래그 |
| 정밀 이동 (느리게, 판정점 표시) | Shift | - |
| 대시 (짧은 무적) | Space / X | 두 번 탭 |
| 공격 | 자동 발사 | 자동 발사 |
| 일시정지 / 소리 / 전체화면 | P (Esc) / M / F | 왼쪽 위 일시정지 버튼 |
| 게임 도중 나가기 | 일시정지 메뉴의 QUIT TO LOBBY (또는 Q) | 일시정지 버튼 → QUIT TO LOBBY |

## 로비

첫 화면이 로비입니다. 게임 화면을 옆으로 넘기면(마우스 드래그, 손가락 스와이프, ←/→ 키, 아래 구석의 화살표 탭) 페이지가 바뀝니다.

- **왼쪽 페이지, PILOT SHOP**: ↑/↓로 기체를 고르고 Enter(또는 카드 탭)로 구매하거나 장착합니다. 출격하면 점수의 1/10과 보스 격파 보너스가 크레딧으로 쌓입니다.
- **가운데, 타이틀**: Enter나 탭으로 출격합니다.
- **오른쪽 페이지, SELECT BOSS**: 보스 카드 중에서 고르고, 선택한 보스의 정보(체력, 페이즈, 공격 종류), 격파 횟수, 최고 기록, SORTIE 버튼이 있습니다.

## 보스

오른쪽 **SELECT BOSS** 페이지에 보스 카드가 나란히 있고, ↑/↓나 카드 탭으로 고른 뒤 SORTIE(또는 선택된 카드를 한 번 더 탭)로 출격합니다. 격파 횟수와 최고 기록은 보스별로 저장됩니다.

| 보스 | 체력 | 생김새 | 공격 |
| --- | --- | --- | --- |
| STRIKER OMEGA | 1600 | 전투기형 로봇 | 개틀링, 유도 미사일, 대공포, 부채꼴 소사, 융단 폭격, 마이크로 미사일 군단, 배럴 롤 사격, 애프터버너 커튼, 지그재그 강습, 돌진, 폭격 비행, 급강하 (12종) |
| AEGIS CORE | 1900 | 금색 고리가 도는 장갑 구체 코어 + 공전하는 포탑 포드 4개 | 포드 일제 사격, 나선 탄막, 빈틈 있는 고리탄, 포드 탄막 벽, 추적 구체, 꽃잎 탄막, 코너 포격, 렌즈 빔, 십자 레이저(회전), 포드 돌진, 궤도 확장, 수축 링 (12종) |

## 스테이지

10개 스테이지(OUTER ORBIT부터 STRIKER NEST까지)로 진행됩니다.

- **1~9스테이지**: 잡졸 웨이브만 나옵니다. 잡졸은 도망가지 않으므로 웨이브를 전멸시켜야 다음 웨이브와 다음 스테이지로 넘어갑니다. 스테이지가 오를수록 잡졸 수와 종류가 늘어납니다.
- **10스테이지**: 웨이브 뒤에 최종 보스 STRIKER OMEGA가 WARNING 연출과 함께 등장합니다.
- **스테이지 사이**: 업그레이드 카드 3장 중 1장(무기, 유도 미사일, 최대 체력, 수리, 보호막, 빠른 대시)을 고릅니다.
- **스테이지 선택**: SELECT STAGE 화면에서 ←/→(또는 노드 탭)로 스테이지를 골라 출격합니다. 클리어한 스테이지는 다시 플레이할 수 있고, 다음 스테이지는 이전 스테이지를 깨야 열립니다.
- **보스 체력**: 보스가 등장할 때 내 화력(티어, 파워)에 맞춰 정해집니다. 최소 5000이고, 최대 화력 기준으로 약 70초 분량입니다.

## 연출과 사운드

- **스테이지별 배경**: 하늘 그라데이션, 성운, 고리 달린 행성에 지형이 더해집니다 (소행성대, 얼음 파편, 사막 모래, 바다 물결, 번개 치는 폭풍 구름, 용암 불씨, 폐허 도시 옥상, 구름 위 하늘).
- **배경음악**: 칩튠 음악을 Web Audio로 실시간 합성합니다. 타이틀·맵, 스테이지, 보스전 곡이 따로 있습니다 (M으로 끄기).
- **타격감**: 큰 적 격추, 피격, 보스 페이즈 전환, 보스 격추 때 화면이 순간 멈춥니다. 섬광 효과와 CRT 느낌의 비네트·스캔라인 필터도 들어갑니다.
- **폭탄**: C나 B 키(모바일은 세 손가락 탭)로 씁니다. 스테이지마다 3발이 주어지고, 적 탄을 전부 지우고 화면의 모든 적에게 큰 피해를 줍니다. 보스에게는 최대 체력의 3% 피해를 줍니다.

## 그래픽

- 잡졸과 보스 스프라이트는 픽셀아트 전용 2배 확대(Scale2x)로 외곽을 매끄럽게 다듬고, 위쪽 하이라이트와 아래쪽 그림자를 자동으로 넣어 입체감을 줍니다.
- 잡졸은 기존보다 2배 크게 나오고, 판정, 대형 간격, 포탑·포드·레이저 위치도 크기에 맞춰져 있습니다.
- 최종 보스 STRIKER OMEGA는 2배 크기(약 96×80)의 거대 기체이고, 공격 예고 범위와 판정도 크기에 맞게 커졌습니다.
- 내 전투기는 15픽셀의 더 정교한 디자인입니다. 티어 2부터는 날개 끝이 포구로 바뀝니다.

## 보스 공격

보스는 기수를 공격 방향으로 돌리고, 탄은 모두 기체의 실제 무기 위치에서 나옵니다.

- **개틀링**: 플레이어 쪽으로 기수를 돌리고 날개 밑 총열이 회전(스핀업)한 뒤, 좌우 총구에서 번갈아 예광탄을 쏩니다. 총구 화염, 반동, 탄피가 보입니다.
- **미사일**: 날개 밑 거치대의 미사일이 하나씩 떨어져 나와 점화한 뒤 플레이어를 추적합니다. 다 쏘면 재장전됩니다.
- **돌진**: 플레이어를 향해 기수를 돌리고, 애프터버너를 모으는 동안 빨간 띠로 경로를 예고한 뒤 들이받습니다.
- **폭격 비행**: 옆으로 선회해 화면을 가로지르며 폭탄창을 열고 폭탄을 떨어뜨립니다. 착탄 지점은 빨간 표적으로 표시됩니다.
- **급강하** (Phase 2+): 기수를 위로 들어 화면 밖으로 상승한 뒤, 그림자 위치로 기수부터 내리꽂힙니다.

체력 66%, 33%에서 배럴 롤을 하며 페이즈가 바뀝니다. 페이즈가 오를수록 공격이 빨라지고 횟수가 늘어나며, 기체에서 연기와 불꽃이 납니다.
플레이어 체력은 하트 5개이고, 피격 판정은 기체 한가운데 한 점뿐입니다. 최고 기록(클리어 시간)은 브라우저에 저장됩니다.

## 구조

- `index.html`: 게임 전체 (Canvas 240×320, 순수 JavaScript, 외부 라이브러리 없음)
  - 보스 스프라이트는 기수가 아래를 향하게 별도 캔버스에 그린 뒤 `boss.ang`만큼 회전해서 그립니다. `hull(x, y)`가 스프라이트 좌표를 화면 좌표로 바꿔 주기 때문에 총구, 미사일 거치대, 엔진 위치에서 정확히 발사됩니다.
  - 공격 패턴은 제너레이터 함수(`function*`)이고 `yield 초`로 타이밍을 제어합니다. 새 패턴은 `sXxx` 함수를 만들어 `POOLS`에 추가하면 됩니다.
  - 효과음은 Web Audio로 실시간 합성합니다.
