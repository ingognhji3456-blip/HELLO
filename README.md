# GLOOMEYE — 픽셀 보스 러시

외눈 괴물 보스 **Gloomeye**의 탄막 패턴을 피하면서 쓰러뜨리는 픽셀 보스전 게임입니다.
빌드 과정 없이 `index.html` 하나만 브라우저로 열면 바로 실행됩니다.

## 조작법

| 동작 | 키보드 | 모바일 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 화면 드래그 |
| 정밀 이동 (느리게, 판정점 표시) | Shift | - |
| 대시 (짧은 무적) | Space / X | 두 번 탭 |
| 공격 | 자동 발사 | 자동 발사 |
| 일시정지 / 소리 끄기 | P (Esc) / M | - |

## 보스 패턴

보스 체력 66%, 33%에서 페이즈가 바뀌며 패턴이 강해집니다.

- **Phase 1**: 원형 탄막, 조준 부채꼴 탄, 회전 나선탄, 탄 비(낙하 경고 후 떨어짐)
- **Phase 2**: 위 패턴 강화 + 조준 레이저(빨간 선으로 예고), 돌진(낙하 지점 경고 후 충격파), 감속 후 재조준 탄
- **Phase 3**: 레이저가 회전하고, 두 패턴을 동시에 쓰는 복합 패턴 추가

플레이어 체력은 하트 5개이며, 피격 판정은 기체 한가운데 한 점뿐입니다. 최고 기록(클리어 시간)은 브라우저에 저장됩니다.

## 구조

- `index.html` — 게임 전체 (Canvas 240×320, 순수 JavaScript, 외부 라이브러리 없음)
  - 보스 패턴은 제너레이터 함수(`function*`)로 작성되어 `yield 초`로 타이밍을 제어합니다. 새 패턴은 `pXxx` 함수를 만들고 `POOLS`에 추가하면 됩니다.
  - 효과음은 Web Audio로 실시간 합성합니다.
