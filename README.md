# STRIKER — 픽셀 보스전

전투기형 로봇 보스 **STRIKER**의 공격을 피하면서 격추하는 픽셀 보스전 게임입니다.
빌드 과정 없이 `index.html` 하나만 브라우저로 열면 바로 실행됩니다.

## 조작법

| 동작 | 키보드 | 모바일 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 화면 드래그 |
| 정밀 이동 (느리게, 판정점 표시) | Shift | - |
| 대시 (짧은 무적) | Space / X | 두 번 탭 |
| 공격 | 자동 발사 | 자동 발사 |
| 일시정지 / 소리 / 전체화면 | P (Esc) / M / F | 상단 전체화면 버튼 |

## 스테이지

10개 스테이지(OUTER ORBIT부터 STRIKER NEST까지)로 진행됩니다.

- **1~9스테이지**: 잡졸 웨이브만 나옵니다. 잡졸은 도망가지 않으므로 웨이브를 전멸시켜야 다음 웨이브와 다음 스테이지로 넘어갑니다. 스테이지가 오를수록 잡졸 수와 종류가 늘어납니다.
- **10스테이지**: 웨이브 뒤에 최종 보스 STRIKER OMEGA가 WARNING 연출과 함께 등장합니다.
- **스테이지 사이**: 업그레이드 카드 3장 중 1장(무기, 유도 미사일, 최대 체력, 수리, 보호막, 빠른 대시)을 고릅니다.
- **스테이지 선택**: SELECT STAGE 화면에서 ←/→(또는 노드 탭)로 스테이지를 골라 출격합니다. 클리어한 스테이지는 다시 플레이할 수 있고, 다음 스테이지는 이전 스테이지를 깨야 열립니다.
- **보스 체력**: 보스가 등장할 때 내 화력(티어, 파워)에 맞춰 정해집니다. 최소 5000이고, 최대 화력 기준으로 약 70초 분량입니다.

### 잡졸 (모두 체력이 있고, 쏘기 전에 예고 동작이 있음)
| 잡졸 | 등장 | 공격 |
| --- | --- | --- |
| 드론 | 1~ | 눈이 분홍색으로 차오른 뒤 조준탄 1발. 가끔 빨간 조준선 후 몸통 급강하 |
| 전투기 | 1~ | 기수를 돌려 빨간 조준선을 보여준 뒤 기수에서 예광탄 연사 |
| 중형기 | 1~ | 포탑이 따라 돌고, 포구가 깜빡이면 부채꼴 탄. 격추 시 아이템 확정 |
| 미사일 발사대 | 3~ | 포드가 노랗게 빛난 뒤 유도 로켓 2발. 로켓은 총으로 격추 가능 |
| 레이저 드론 | 5~ | 렌즈 충전과 함께 초록 가이드 선이 보인 뒤 아래로 레이저 |

아이템: **P**는 무기 강화(최대 5단계), **R**은 수리입니다.

**티어 1~5**: 티어마다 파워가 1~5단계(탄 1, 2, 3, 6, 8줄기)이고, 파워 5에서 P를 더 먹으면 다음 티어로 변신하며 탄이 1발로 돌아갑니다. 대신 탄이 더 강해지고 화려해집니다.

| 티어 | 기체 | 탄 | 데미지 | 추가 |
| --- | --- | --- | --- | --- |
| 1 | 파란 기본기 | 하늘색 바늘탄 | 1 | |
| 2 | 금색 | 금빛 플라스마 | 2 | 날개 포 총구 화염 |
| 3 | 초록 | 분홍 에너지 구체 | 3 | 관통 레이저 창 (3발마다) |
| 4 | 보라 | 보라 레이저 볼트 | 4 | 관통 창, 주위를 도는 불꽃 2개 |
| 5 | 무지개로 변하는 흰 기체 | 무지개 노바탄 | 6 | 관통 창 (2발마다), 불꽃 4개 |

이어하기를 하면 티어는 유지되고 파워만 1단계 내려갑니다.

## 보스 공격

보스는 기수를 공격 방향으로 돌리고, 탄은 모두 기체의 실제 무기 위치에서 나옵니다.

- **개틀링**: 플레이어 쪽으로 기수를 돌리고 날개 밑 총열이 회전(스핀업)한 뒤, 좌우 총구에서 번갈아 예광탄을 쏩니다. 총구 화염, 반동, 탄피가 보입니다.
- **미사일**: 날개 밑 거치대의 미사일이 하나씩 떨어져 나와 점화한 뒤 플레이어를 추적합니다. 다 쏘면 재장전됩니다.
- **돌진**: 플레이어를 향해 기수를 돌리고, 애프터버너를 모으는 동안 빨간 띠로 경로를 예고한 뒤 들이받습니다.
- **폭격 비행**: 옆으로 선회해 화면을 가로지르며 폭탄창을 열고 폭탄을 떨어뜨립니다. 착탄 지점은 빨간 표적으로 표시됩니다.
- **급강하** (Phase 2+): 기수를 위로 들어 화면 밖으로 상승한 뒤, 그림자 위치로 기수부터 내리꽂힙니다.

체력 66%, 33%에서 배럴 롤을 하며 페이즈가 바뀝니다. 페이즈가 오를수록 공격이 빨라지고 횟수가 늘어나며, 기체에서 연기와 불꽃이 납니다.
플레이어 체력은 하트 5개이고, 피격 판정은 기체 한가운데 한 점뿐입니다. 최고 기록(클리어 시간)은 브라우저에 저장됩니다.

## 구조

- `index.html`: 게임 전체 (Canvas 240×320, 순수 JavaScript, 외부 라이브러리 없음)
  - 보스 스프라이트는 기수가 아래를 향하게 별도 캔버스에 그린 뒤 `boss.ang`만큼 회전해서 그립니다. `hull(x, y)`가 스프라이트 좌표를 화면 좌표로 바꿔 주기 때문에 총구, 미사일 거치대, 엔진 위치에서 정확히 발사됩니다.
  - 공격 패턴은 제너레이터 함수(`function*`)이고 `yield 초`로 타이밍을 제어합니다. 새 패턴은 `sXxx` 함수를 만들어 `POOLS`에 추가하면 됩니다.
  - 효과음은 Web Audio로 실시간 합성합니다.
