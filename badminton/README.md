# 셔틀 스매시 — 배드민턴 단식

옆에서 보는 실내 경기장에서 치는 배드민턴 단식 게임입니다. 빌드 과정 없이 `badminton/index.html` 하나만 브라우저로 열면 바로 실행됩니다. 첫 화면 뒤에서는 CPU끼리 데모 경기를 합니다.

## 모드

| 항목 | 선택지 |
| --- | --- |
| 모드 | 1인 (CPU 대전) / 2인 (한 키보드 또는 한 화면) |
| 난이도 | 쉬움 (상대 샷의 착지 지점 표시) / 보통 / 어려움 |
| 점수 | 11점 (10:10부터 2점 차, 최대 15점) / 21점 (20:20부터 2점 차, 최대 30점) |
| 경기 | 단판 / 3게임 2선승 |

랠리 포인트제라 랠리를 이긴 쪽이 1점을 얻고 다음 서브를 넣습니다.

## 조작법

| 동작 | 1인 키보드 | 2인: 1P (왼쪽, 파랑) | 2인: 2P (오른쪽, 빨강) | 터치 |
| --- | --- | --- | --- | --- |
| 이동 | ← → / A D | A D | ← → | ◀ ▶ |
| 점프 | ↑ / W / Space | W | ↑ | 점프 |
| 스매시 | Z / J | F | , (또는 숫자패드 1) | 스매시 |
| 클리어 | X / K | G | . (또는 숫자패드 2) | 클리어 |
| 드롭 | C / L | H | / (또는 숫자패드 3) | 드롭 |
| 일시정지 / 소리 | Esc, P / M | | | 오른쪽 위 버튼 |

샷 버튼은 셔틀을 맞히는 높이에 따라 다른 샷이 나갑니다.

- **스매시**: 머리 위에서 치면 스매시 (점프 중이면 점프 스매시), 가슴 높이면 빠르고 낮은 드라이브, 네트 바로 앞 낮은 위치면 푸시.
- **클리어**: 어디서 치든 높고 깊게 넘깁니다 (낮은 데서 치면 리프트).
- **드롭**: 높은 데서 치면 네트 앞에 떨어지는 드롭, 네트 앞 낮은 데서 치면 헤어핀.
- **서브**: 스매시 = 빠르고 깊은 플릭 서브, 클리어 = 하이 서브, 드롭 = 숏 서브. 숏 서브가 쇼트 서비스 라인(네트에서 1.98 m) 앞에 떨어지면 서비스 폴트입니다.
- **길이 조절**: 이동키를 네트 쪽으로 누른 채 치면 짧게, 반대쪽으로 누른 채 치면 길게 갑니다. 길게 칠수록 아웃 위험이 커집니다.

## 타이밍

버튼을 누르면 0.03~0.22초 동안 라켓이 셔틀을 맞힐 수 있습니다. 셔틀이 손이 닿는 범위에 들어오기 약 0.085초 전에 누르면 **PERFECT**가 떠서 샷이 더 빠르고 정확해집니다. 너무 일찍 누르면 빗맞아 속도가 떨어지고 네트에 걸릴 수 있습니다. 스매시를 치면 화면이 흔들리고, 퍼펙트 스매시는 순간 멈춥니다.

## 규칙

- 코트는 실제 규격(13.40 m × 6.10 m, 네트 높이 1.55 m)이고, 단식이라 뒤쪽 라인까지가 인입니다. 선에 걸치면 인.
- 셔틀이 네트에 걸려 자기 쪽에 떨어지면 친 쪽의 실점. 네트 테이프를 스치고 넘어가면 "넷 코드"로 그대로 진행됩니다.
- 네트에 바짝 붙어 테이프보다 낮게 떨어지는 셔틀은 라켓이 네트에 닿기 때문에 칠 수 없습니다.
- 셔틀이 떨어진 자리에 IN/OUT 표시가 남습니다.

## 구조

- `index.html` 하나에 게임 전체가 들어 있습니다 (Canvas 960×540 논리 해상도, 순수 JavaScript, 외부 라이브러리 없음, 글꼴만 Google Fonts).
- 셔틀콕은 중력과 속도 제곱에 비례하는 공기저항으로 1/240초 단위로 계산합니다. 그래서 빠르게 출발해도 금방 느려지고 끝에서 가파르게 떨어집니다.
- 샷은 같은 물리 계산으로 궤적을 미리 돌려 보고, 목표 지점에 떨어지면서 네트를 넘는 발사 각도와 속도를 이분 탐색으로 찾습니다 (`shotFast`, `shotLob`, `shotSoft`).
- CPU도 같은 계산으로 셔틀 궤적을 예측해 칠 위치와 점프 시점을 정하고, 사람과 같은 스윙 판정으로 칩니다. 난이도마다 반응 시간, 이동 속도, 샷 정확도, 아웃 판단, 스매시 빈도가 다릅니다.
- 효과음과 관중 함성은 Web Audio로 실시간 합성합니다. 설정, CPU 상대 전적, 최장 랠리, 최고 스매시 속도는 브라우저에 저장됩니다.
